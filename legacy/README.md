# Historical implementation

This directory preserves the original public implementation from commit
`abfedd546d152eb697639c24fb5bf032542af72d` for inspection and provenance.

It is **not** the revised experiment entry point, and its results do not apply
to the revised diagnostic-control method. The old scripts contain unresolved
protocol/model differences and are not supported as a reproduction workflow.

Use `../training.py`, `../prepare_data.py`, and the `../fafirec/` package.
