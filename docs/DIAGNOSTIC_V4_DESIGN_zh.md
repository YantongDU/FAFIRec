# 从FAFIRec设计初衷重新检验性能瓶颈

本轮以“根据已有行为证据决定如何整合协同与文本信息”为出发点。原稿的两维固定teacher诊断、共享编码器和全局MK-MMD，与前轮独立残差模型，均保留为历史版本。本轮在独立分支 `codex/diagnostic-complementarity` 实现新的组合实验，原模型和ACE基线源码、数据及结果保持冻结。

## 已核实的限制与对照

现有训练器每用户每轮只取最后50个监督转移：全部451,372个训练转移中，每轮只使用217,893个。约一半较早转移永久未参与训练。新的 `CoverageDataset` 提供两种策略：按epoch随机抽取每用户历史窗口，或将所有训练转移分成不重叠的最多50位置窗口。后者每轮覆盖所有转移，窗口边界重置位置编码与上下文；推断仍只看最近50个事件。它是训练数据组织的修改，应同样用于ACE对照。

seed2025验证NDCG@50：原ACE为0.270332，随机窗口为0.272560，全转移窗口为0.275948。后续统一采用全转移窗口的ACE型骨干，并保留它独立评分的对照。上述仅为验证结果，不替代最终五次测试。

全训练历史EASE与ACE有互补，但EASE独立排序较弱。将EASE拟合范围也限制为最后51个事件时，既定混合网格没有超过ACE；因此长历史覆盖是重要混杂因素。新的全转移ACE对照用于处理这一问题。另有流行度校准控制，防止把热门先验修正误当成诊断的收益。

## 方法来源与本轮改动

- [EASE，WWW 2019](https://arxiv.org/abs/1905.03375)给出带零对角约束的线性协同重构及闭式解。本轮将其作为成熟协同分支，不将它归为新贡献。
- [ACE，SIGIR 2026](https://arxiv.org/abs/2605.29322)提供文本谱初始化与原始点积分数的强序列骨干。本轮的独立实现沿用该数学结构；全转移窗口属于显式训练布局改动。
- [Rethinking Semantic–Collaborative Integration，SIGIR 2026](https://arxiv.org/html/2604.22195v1)讨论shared/private证据与互补，提示全局对齐可能损伤各自独有的信号。
- [AlphaFuse，SIGIR 2025](https://arxiv.org/html/2504.19218v2)保留语义子空间，[EnsRec预印本](https://arxiv.org/html/2512.17820v3)采用独立ID/text模型后融合。这些已有机制应准确引用；独立分支和简单分数相加本身不能作为本轮新颖性证明。

## 训练集内部的诊断代理

对每用户原训练序列长n，留出尾部 `min(10,max(1,int(.2*n)))` 个事件，同时至少保留两个前缀事件。诊断用ACE型teacher只在此前缀训练，固定135轮，既不按留出尾部早停，也不评分外层验证/测试。诊断用EASE也只拟合前缀。

内层尾部的前半段作为已观察事件，后半段作为训练gate的多正例目标块。七维特征包括历史长度、最近至多两次已观察预测的相对NLL/排名统计、当前预测熵差和top20重叠。没有待预测目标作为特征。外层推断继续使用固定内层代理计算这些诊断，不换成已拟合全部训练事件的模型，因此不会将训练尾部的拟合误差误称为样本外诊断。该代理仍是此前缀训练的last50模型，不能称作全转移强骨干自身的校准可靠性。

所有特征归一化统计只在内层gate训练样本拟合。候选频次变换也固定内层统计，外层只输入相同物品映射下的完整训练频次，不使用验证/测试频次。

## 分数融合与可选关系对齐

每个视图在未观察候选集上按用户前缀标准化分数；候选过滤不依赖待预测标签。融合为：

```text
score(u,i) = z(sequence_score(u,i))
           + beta * z(log1p(train_count(i)))
           + alpha * 2*sigmoid(controller(u,i)) * z(collaborative_score(u,i)).
```

比较global、仅历史长度、完整诊断和诊断×候选频次/分歧四类控制器。零初始化时gate为1，恢复同一全局混合；alpha=beta=0回到所选序列骨干的排序，代码实际核对该等价关系。门控仅在内层训练块拟合20轮，多正例CE按用户平均，外层验证只选择候选配方。

对齐采用显式物品身份对应的score-profile目标，替代匿名分布MMD。令X为二值训练用户–物品矩阵，S为静态文本构造的正余弦top30行归一关系，B为协同算子：

```text
min_B ||X-XB||² + lambda*||B||²
    + mu*||diag(w)^(1/2) (XB-XS)||², subject to diag(B)=0.
```

文本中心只用训练见过的物品。共享用户控制分数s生成固定对齐权重 `w=2*sigmoid(-s)`；global对应均匀权重。该目标有带对角约束的闭式解，代码核对KKT残差，并以独立逐列最小二乘作单元测试。mu=0严格退回EASE；这不是原MK-MMD，原核分布理论不应继续套用。

## 选择与归因约束

先在seed2025的验证集比较明确列出的门控、混合系数和对齐权重，再固定有限配方及匹配控制，复验2025–2029。所有最终模型均在测试评分前锁定，主结果只选择一个共同配方。已有测试集在历史开发中被观察，仍属于透明的迭代benchmark。

本轮单种子最优为均匀对齐+全局融合：0.289441；无对齐全局融合为0.289385，差值只有0.000055。完整诊断和候选门控暂未超过简单全局融合。因此当前证据不支持将总收益归因于诊断机制，更不支持将微小对齐差值提前称作稳定收益。最终报告须分别展示原ACE、全转移ACE、热门校准、全局融合和诊断/对齐控制，并以真实五次结果决定保留哪些复杂度。
