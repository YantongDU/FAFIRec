# FAFIRec 改进原因与实际实验结果

报告日期：2026-11-17。锁定配置的五个训练种子（2025, 2026, 2027, 2028, 2029）和三个匹配对照均已完成，共15组主实验；全部15个选中检查点已独立重载，逐用户输出与指标完全一致。另完成五种子的CF学习率候选验证比较，并在锁定基线后核对选中CF的五种子测试输出与重载。

结果为每个种子的用户宏平均，再计算五种子均值与样本标准差。以下结论按实际数值生成，保留整体与冷用户结果，不只选择有利分组。

## 本轮结论

- 全体相对新CF（验证选择学习率）：Recall@10均值低于该对照（相对变化-2.38%）；NDCG@10均值低于该对照（相对变化-1.84%）。
- 冷用户相对新CF（验证选择学习率）：Recall@10均值低于该对照（相对变化-1.66%）；NDCG@10均值低于该对照（相对变化-0.09%）。
- 全体相对新均匀诊断对照：Recall@10均值低于该对照（相对变化-0.04%）；NDCG@10均值低于该对照（相对变化-0.16%）。
- 冷用户相对新均匀诊断对照：Recall@10均值高于该对照（相对变化+0.61%）；NDCG@10均值高于该对照（相对变化+0.50%）。

主要判断同时参照验证选择的更强CF、匹配uniform以及冷用户表现；不能只因为完整模型高于采用较小学习率的匹配CF，就称为整体胜利。是否能把收益归于诊断控制，还必须看匹配uniform及配对不确定性；不能由新旧完整模型的综合差异直接推断。当前没有完成原论文全部竞争模型，不据此宣称新SOTA或论文达到Strong Accept。

## 原因分析：证据与假设

- 原随机投影的文本/ID平均范数比为1.65–1.90；原始向量按0.5混合不代表方向各占一半。CF学生首轮验证NDCG@50为0.154367–0.160788，uniform多模态首轮为0.117744–0.123481。共同多模态路径出现优化断层，不能只归咎诊断。
- 原五个教师都在第30轮预算边界最优，验证NDCG@50为0.150856–0.157358；继续CF后达到0.229269–0.233125。这支持充分训练教师，但不能证明延长教师预算必然使多模态模型超越匹配CF。
- 原诊断对齐权重在全集上的有效样本量为5920.6–5932.7/5950，接近均匀。它是全集描述统计，实际权重仍按批次计算，不能当作诊断已学出强用户区分的证据。
- 记录的seed2025固定初始批次上，投影的加权对齐/推荐梯度范数比为0.745、cos为+0.716。不同参数的梯度方向并不一致，不能武断称MK-MMD普遍与推荐损失冲突。

原30轮教师的seed2025初始化探针（仅初始化后验证，非最终模型）：

| 投影初始化 | CF门先验 | 初始验证NDCG@50 |
|---|---:|---:|
| random | 0.5 | 0.102270359320 |
| random | 0.9 | 0.149616179825 |
| ridge | 0.5 | 0.140271037987 |
| ridge | 0.9 | 0.151723925508 |

这些探针表明CF保留型初始化能减小初始性能断层；它们不替代最终多种子测试，也不能直接解释全部最终差异。

## 最终代码与训练设置

- 推理与融合公式保持不变，诊断线性系数和截距仍零初始化。ridge只用训练正反馈序列已见的唯一物品、静态文本与固定教师ID向量拟合起点，投影与两侧融合门随后可训练。未在正反馈中出现的物品仍可能作为负样本获得梯度，不能称其完全没有CF信号。
- 最终设置：projection=ridge，CF先验0.9，ridge正则1，alignment=0.03，gateLR倍率1；学生Adam lr=0.0003，教师lr=0.001，coupled L2=1e-5，教师/学生最多150轮，patience10，min_epochs30，epoch0参与选模。
- min_epochs30仅保证达到最早允许停止的轮数；之前仍保存全局最优检查点、积累stale，不在第30轮重置patience。epoch0仍可被最终选中，并不强制采用更差的更新模型。
- 五个种子中的CF/uniform/diagnostic共享各自同一个选中教师、对应固定训练诊断与匹配学生训练/选择规则。uniform固定诊断得分及用户对齐权重，仍有可训练全局维度偏置与物品门，不是永远严格0.5/0.5平均。
- d64、batch2048、max_len50、一层两头、dropout0.1；保留真实Qwen3-Embedding-0.6B电影标题/年份/类型向量。
- 数据仍为5950用户、3883电影、574619条正反馈；逐用户按时间80/10/10取整，训练457322、验证54770、测试62527。全目录排除已观察历史，多目标Recall/NDCG按用户宏平均，冷/暖各595用户。与原论文表II的未公开子集不同，不能直接覆盖为同一表格复现。
- 默认legacy选项保留：random投影、CF先验0.5、gateLR倍率1、include_initial_checkpoint=false、min_epochs0、teacher_lr=null继承lr。旧运行仍由冻结旧树重载，新实验使用新输出目录。
