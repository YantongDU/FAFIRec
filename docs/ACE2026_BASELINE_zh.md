# 新增基线：ACE（SIGIR 2026）

任务日期：2026-11-19。此次比较针对已经完成的 ML-1M 实验，旧源码、模型和结果保持冻结。

## 来源与选择

- 论文：[ACE: Anisotropy-Controllable Embedding for LLM-enhanced Sequential Recommendation](https://arxiv.org/abs/2605.29322)，[SIGIR 2026 DOI](https://doi.org/10.1145/3805712.3809911)。
- 作者代码：[DCheol/ACE](https://github.com/DCheol/ACE)，固定提交 `3e099052d9759b841a5192a2ae20a3b3ac02c6c6`，提交日期2026-07-13。
- 方法核心是由静态文本向量的奇异值构造可控谱初始化，随后正常训练序列推荐模型。它与现有文本增强推荐任务匹配，无需新增用户画像、图像或在线大模型调用。
- 官方完整代码仅保留在忽略目录 `data/ACE_reference`，用于只读核对和本地等价测试；仓库未声明许可证，不将其复制进公开分支。新增模型按照论文公式和通用注意力运算独立实现。

检索还发现作者公开的 [EnsRec](https://github.com/snap-research/EnsRec)，其[预印本](https://arxiv.org/abs/2512.17820)研究ID/text独立训练与集成，和当前改造方向接近。尚未核实其正式顶会录用，本轮主对照选择正式发表的ACE；没有为EnsRec生成或借用本地分数。若论文采用独立分支，应准确引用并区分这些已有贡献，不能把独立训练本身作为新颖性证明。

## 保留的方法细节

非PAD物品文本矩阵 `F` 不做中心化，进行 thin SVD。截取前 `d` 维后，初始化为 `U_d * sqrt(S_d² / (S_d² + lambda))`，再按整个矩阵的总体标准差缩放到 `scale`，插入全零PAD行。随后整张物品表可训练；`lambda` 只控制初始化，不是训练 weight decay，也不在每个batch额外加入LAE损失。

序列编码采用原生 SASRec 风格的后归一化注意力/前馈结构。用户和物品输出不额外做L2归一化，使用原始点积和标准全目录CE。训练CE保留PAD零logit及其他已知训练正例，遵循作者实现；PAD通过embedding lookup保持零梯度。不能用现有cosine模型直接替代，否则初始化尺度会被抵消。

## 统一比较的边界

共同输入为已冻结的 5,950 用户、3,883 物品 ML-1M 数据、逐用户时间80/10/10划分，以及同一份Qwen3-Embedding-0.6B标题/年份/类型向量。验证历史为train，测试历史为train+完整validation；全目录排除已观察历史，按完整正例块计算用户宏平均Recall/NDCG@10/@50，仍按验证NDCG@50选模型。

作者论文使用其他数据集、leave-one-out、其他文本编码器和原始训练样本组织。因此本次名称应为 **ACE-SASRec（共同输入、统一评估协议适配）**，不能称原论文数值复现。本轮训练与现有FAFIRec使用相同的最后50个shifted监督位置；作者原生one-prefix/one-target数据加载方式不同。输入先由左PAD转换为右PAD，以保留官方位置编码和最后有效状态语义。评估器、目标、分组和候选集复用现有实现，训练损失保持各方法定义。

ACE采用作者ML-1M配置的128维、2层、2头、FFN256、hidden dropout0.5、attention dropout0.3、GELU、LayerNorm epsilon1e-12、Normal(0,0.02)随机编码器初始化和256用户序列批量。它从随机编码器和ACE物品表开始，完全不加载旧CF权重。FAFIRec使用64维、1层、批量2048及CF预训练，二者不称作容量或计算量严格匹配；应同时记录实际参数量、优化步数和耗时。

## 验证选择计划

先在seed2025固定比较 `lambda={0,50,500}` × `scale={0.1,0.5,1}`，学习率0.0005，Adam、weight decay0、不做梯度裁剪、FP32，最多400轮、最少30轮、每5轮验证、连续3次验证未提高后早停，epoch0可以被选中。固定最优lambda/scale后，再比较学习率0.001和0.0001，并与已有0.0005结果一同按验证NDCG@50选择；随后锁定同一套超参数完成2025–2029五种子。

训练和调参入口不评估测试。全部最终模型锁定后显式测试，独立重新加载验证/测试排名并从CSV重算指标。报告所有五种子及均值/样本SD、配对差和有限种子不确定性。此前测试分数已经公开用于研究开发，仍属于透明迭代benchmark，不宣称未触碰确认集。
