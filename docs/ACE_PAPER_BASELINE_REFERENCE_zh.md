# ACE原论文中的baseline指标：文献参考表

整理日期：2026-11-19。以下28行、112个指标逐格提取自作者论文 Table 1，没有进行本地重跑。

来源：[ACE（SIGIR 2026），Table 1](https://arxiv.org/html/2605.29322v1#S3.T1)。

**ML-20M 与当前 ML-1M 是不同数据集。此表不能与本机FAFIRec的ML-1M实测数值混为同一主对比表。**

原论文采用5-core、leave-one-out、full-sort且不额外过滤候选；文本默认text-embedding-3-large，另有其他编码器实验，结果平均4次运行。当前实验是逐用户时间80/10/10、全目录排除已观察历史、多正例用户宏平均、Qwen3-Embedding-0.6B及5种子。

表中保持论文均值精度，未补造标准差；也不把原文显著性标记当作我们已独立核验的显著性结论。
